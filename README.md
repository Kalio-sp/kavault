# KAVAULT ⬛

KAVAULT — это полностековая платформа для организации знаний, трекинга обучения и интервального повторения (SRS). Проект выполнен в минималистичном стиле «Editorial Tech» с поддержкой тёмной/светлой темы и полноценной интернационализацией (EN, RU, JA).

## 🚀 Основной функционал

- **Мультиязычность (i18n):** Мгновенное переключение интерфейса между английским, русским и японским языками через глобальный React Context.
- **Трекер активности (Heatmap):** Интерактивный график активности в стиле GitHub, визуализирующий регулярность обучения (Стрики, Цели).
- **База знаний (Developer Hub & GitHub Collection):** Сохранение полезных статей, видео и open-source репозиториев с возможностью писать Markdown-заметки.
- **Японский хаб (SRS):** Система интервального повторения для изучения иероглифов, слов и грамматики (Двусторонние карточки).
- **Граф знаний:** Визуализация связей между сохраненными материалами и темами.
- **Темы оформления:** Сквозная поддержка Dark/Light модов с сохранением пользовательских предпочтений.

## 🛠 Стек технологий

**Frontend:**

- React (Vite) + TypeScript
- CSS-переменные (Свой UI-kit без сторонних библиотек компонентов)
- Lucide React (Иконки)

**Backend:**

- NestJS (TypeScript)
- PostgreSQL (в Docker)
- Prisma (ORM)
- REST API
